# Digital University Portal

Готовий full-stack варіант твого HTML-порталу.

## Що змінилося

- Реєстрація та вхід тепер виконуються на сервері.
- Паролі та секретні слова зберігаються як хеші через bcrypt.
- Акаунти, завдання, студентський квиток і розклад зберігаються в SQLite.
- Дані різних користувачів ізольовані один від одного.
- Сесія входу зберігається на сервері.
- Frontend залишено максимально близьким до оригінального `DU app.html`.

## Запуск на ПК

Потрібен Node.js 18+.

```bash
npm install
```

Створи змінну `SESSION_SECRET` (у production обов'язково зміни її на довгий випадковий секрет).

```bash
npm start
```

Після цього відкрий:

`http://localhost:3000`

## Розміщення в інтернеті

Завантаж цю папку на Node.js-хостинг (наприклад Render, Railway або VPS), виконай `npm install` і запускай `npm start`.

Для production:
- використовуй HTTPS;
- задай сильний `SESSION_SECRET`;
- для великого навантаження краще перейти з SQLite на PostgreSQL;
- для реального відновлення пароля краще додати email/OTP замість секретного слова.

## Структура

- `public/index.html` — твій сайт
- `server.js` — API та сервер
- `package.json` — залежності
- `university.db` — створюється автоматично при запуску
